## 🗺️ C++ 学习路线思维导图

### 1️⃣ C++ 基础语法

- **数据类型**
  - `int` · `float` · `double` · `char` · `bool`
- **流程控制**
  - `if` · `switch` · `for` · `while` · `do while`
- **函数**
  - 参数传递 · 返回值 · 函数重载 · 默认参数
- **命名空间**
  - `namespace`

### 2️⃣ 指针与引用（🔴 最重要）

- **指针基础**
  - 一级指针 · 二级指针 · 指针运算 · 空指针
- **引用**
  - 左值引用 · 右值引用 · 引用本质
- **const 限定符**
  - const 变量 · const 函数 · const 对象 · const 与指针组合
- **面试重点** ⭐
  - 指针 vs 引用区别 · 野指针 · 悬空指针 · nullptr

### 3️⃣ 面向对象（OOP）

- **类与对象**
  - 成员变量 · 成员函数 · this 指针
- **封装**
- **继承**
  - `public` · `protected` · `private`
- **多态**
  - 虚函数 · 虚析构 · 虚函数表
- **构造与析构**
  - 构造函数 · 拷贝构造 · 析构函数 · 赋值运算符

### 4️⃣ 内存管理

- **内存分区**
  - 栈 · 堆 · 全局区 · 常量区
- **动态内存**
  - `new` · `delete` · `new[]` · `delete[]` · `malloc` / `free`
- **面试重点** ⭐
  - 内存泄漏 · 野指针 · 悬空指针 · RAII

### 5️⃣ STL（标准模板库）

- **顺序容器**
  - `vector` · `deque` · `list`
- **关联容器**
  - `map` · `set` · `unordered_map` · `unordered_set`
- **容器适配器**
  - `stack` · `queue` · `priority_queue`
- **迭代器**
- **常用算法**
  - `sort` · `find` · `count` · `for_each`

### 6️⃣ 智能指针

- `unique_ptr` · `shared_ptr` · `weak_ptr`
- **面试重点** ⭐
  - 引用计数 · 循环引用 · weak_ptr 作用 · RAII 思想

### 7️⃣ C++11/14 新特性

- `auto` · `lambda` · `nullptr` · `range-for`
- `using` · 移动语义（move） · 完美转发

### 8️⃣ 多线程编程

- **核心组件**
  - `std::thread` · `mutex` · `lock_guard` · `unique_lock`
  - `condition_variable` · `atomic`
- **面试重点** ⭐
  - 死锁 · 竞态条件 · 线程同步 · 线程池思想

### 9️⃣ 模板元编程

- 函数模板 · 类模板 · 泛型编程

### 🔟 设计模式

- 单例模式 · 工厂模式 · 观察者模式 · 策略模式 · 责任链模式

### 1️⃣1️⃣ 项目实战

- 学生管理系统
- 通讯录管理系统
- 文件管理系统
- Socket 聊天室
- HTTP 服务器
- 车载信号模拟系统

> 💡 **学习建议**：按照上述路线循序渐进地学习，重点掌握指针、内存管理和 STL，这些是 C++ 的核心内容。
