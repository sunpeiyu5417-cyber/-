## 二、学习优先级

### 🔥 第一阶段（决定能否过面试）
1. 数组 + 双指针 + 滑动窗口
2. 链表（反转 + 快慢指针）
3. HashMap + LRU
4. 二叉树 BFS/DFS
5. 堆 TopK
6. 动态规划（背包 + LIS）

### ⚙️ 第二阶段（拉开差距）
1. 图（Dijkstra / 拓扑排序）
2. 单调栈 / 单调队列
3. 设计题（LRU / LFU / 线程池）

---

## 三、车载场景应用

| 数据结构 | 车载应用 |
|---------|---------|
| 数组 + 队列 | CAN信号处理、数据缓冲 |
| 哈希表 | ECU信号索引、缓存 |
| 二叉树 | 信号解析树、配置结构 |
| 堆 | 任务调度、优先级处理 |
| 图 | ECU依赖关系、路由网络 |
| DP | 路径规划、最优调度 |

---

## 四、核心刷题方向

- **必背**：两数之和、反转链表、LRU、二叉树遍历
- **加分**：Dijkstra、背包、设计题
- **拉满**：所有星标标记（⭐）的题目
